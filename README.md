# Tylina website

This repository contains the public website for [Tylina](https://tylina.github.io/), a document-first Typst desktop editor.

The desktop application is proprietary software. This repository contains only the public website and does not contain the Tylina application source code.

## Local preview

```bash
npm install
npm run dev
```

Run `npm test` before publishing. The site is a static Vite build; `main` is deployed to GitHub Pages by `.github/workflows/pages.yml`.
